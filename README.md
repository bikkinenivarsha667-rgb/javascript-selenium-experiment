# JavaScript Testing Using Selenium

## Aim
To write a simple JavaScript program and test it using Selenium WebDriver.

## Tools Required
- Java JDK
- Apache Maven
- Selenium WebDriver
- JUnit
- Google Chrome

## Procedure
1. Created a JavaScript increment button.
2. Configured Selenium and JUnit using Maven.
3. Opened the HTML page using Selenium.
4. Clicked the Increment button.
5. Verified that the output changed from 0 to 1.

## Expected Output
Tests run: 1, Failures: 0, Errors: 0
BUILD SUCCESS

## Result
The JavaScript program was tested using Selenium WebDriver.
